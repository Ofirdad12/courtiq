# CourtIQ Play-by-Play Command Center v180

Transforms the imported event feed into an evidence-first game-flow workspace.

## Adds
- verified scoring runs from source score snapshots
- lead-change count and turning points
- turnover-burst windows
- offensive-rebound event pressure
- clutch window (Q4/OT, <=2:00, margin <=5)
- player event pulse
- coach signals with evidence and coach-check prompts
- quick evidence filters for runs, turnovers, OREB and clutch events

## Analysis standard
All conclusions remain source-event signals. They do not infer tactical cause or full possessions unless the source explicitly supports it. Video review remains required for tactical conclusions.
